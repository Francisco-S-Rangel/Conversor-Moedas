Description: The project basically consists of a currency converter, where the user can choose a main currency and other secondary currencies to see the conversion of the value between them. The project has more than 20 currencies and the conversion works from any main currency to any secondary currency (e.g. from Canadian dollar to BRL and Bolivian).

Descrição: O projeto consiste basicamente em um conversor de moedas, onde o usuário pode escolher uma moeda principal e outras moedas secundarias para ver a conversão do valor entre elas. O projeto possui mais de 20 moedas e a conversão funciona de qualquer moeda principal para qualquer moeda secundaria (Ex: de dólar canadense para BRL e Boliviano)
